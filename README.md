# آيات القرآن

تطبيق فلاتر بسيط يعرض قائمة بسور القرآن الكريم مع عدد الآيات في كل سورة، بالإضافة إلى إجمالي عدد آيات القرآن الكريم.

## الميزات
- عرض إجمالي عدد آيات القرآن الكريم (6236 آية).
- قائمة بجميع سور القرآن الـ 114 مع اسم السورة ورقمها وعدد آياتها.
- واجهة مستخدم بسيطة وداعمة للغة العربية وتنسيق من اليمين إلى اليسار (RTL).
- متوافق مع كافة المنصات (iOS، Android، Web، Windows، macOS، Linux).

## طريقة التشغيل
1. تأكد من تثبيت [Flutter](https://flutter.dev/docs/get-started/install).
2. قم بتشغيل الأمر `flutter pub get` لتنزيل الحزم المطلوبة.
3. قم بتشغيل التطبيق باستخدام الأمر `flutter run`.

## حول CouldAI
تم إنشاء هذا التطبيق باستخدام [CouldAI](https://could.ai)، وهو أداة ذكاء اصطناعي لبناء التطبيقات متعددة المنصات. تقوم الأداة بتحويل الأوامر النصية إلى تطبيقات أصلية جاهزة للإنتاج عبر الاستعانة بوكلاء ذكاء اصطناعي مستقلين لإنشاء وتطوير واختبار ونشر التطبيقات.
